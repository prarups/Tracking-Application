# Custom Project Rules

- **Do NOT create default demo roles or users** (`manager`, `techlead`, `john_dev`, `sarah_qa`). Only the `admin` superuser should exist in the database.
- **Do NOT seed default demo department groups** (`DEV`, `QA`, `SUP`, `HR`, `FIN`, `ACC`, `OPS`, `MKT`), projects, or tickets. Only groups and tickets created explicitly by the user must exist in the database.
